# پلتفرم عملیاتی سازمانی — هلدینگ کاشی و سرامیک

پایلوت ۹۰ روزه «پلتفرم عملیاتی سازمانی پلاگین‌محور» برای هلدینگ آراد سرام پیشرو، صنایع کاشی اصفهان، کاشی نیلو و لیان کاوش فراز.

## وضعیت فعلی — فاز ۱ (پایلوت) + بازتعریف تاکسونومی

| پلاگین (لایه) | وضعیت | توضیح |
|---|---|---|
| اتوماسیون اداری و دبیرخانه (عملیات) | فعال | ثبت نامه (وارده/صادره/داخلی)، کارتابل، ارجاع، **پیوست فایل**، دستیار AI با HITL |
| انبار و لجستیک (عملیات) | فعال | موجودی به تفکیک کالیبر/درجه، اسناد رسید/حواله/انتقال/شمارش، قطعی‌سازی تراکنشی، درخواست کالا |
| مستر دیتا محصول و شرکا (بستر) | فعال | محصول کاشی (خط/رنگ/ابعاد/تبدیل واحد)، شرکا (رکورد طلایی + نمونه شرکتی) |
| داشبورد و حاکمیت (بستر) | فعال | KPI هلدینگ/شرکت، کاتالوگ ۳۱ پلاگین، پرچم‌های ویژگی، کانکتورها، کاتالوگ گزارش‌ها، مصرف AI |
| اعلان‌های بلادرنگ | فعال | WebSocket با بلیت HMAC + پوشش polling |
| سرویس‌های هسته (ADR-009) | فعال | زمان‌بند (پردازشگر Outbox + پایش سلامت)، ذخیره‌سازی، دروازه AI، فلگ‌ها، یکپارچه‌سازی، گزارش‌سازی |
| ۲۴ پلاگین دیگر (مالی/تولید/HR/هوشمندی) | ثبت در رجیستری | فاز تحقق P2 تا P5 با وابستگی‌ها — چشم‌انداز کامل سند منبع |

## معماری

مونولیت ماژولار + رجیستری پلاگین دیتابیس‌محور با **تاکسونومی سه‌لایه** (بستر/عملیات/هوشمندی — ADR-008) + چندمستأجری («شرکت = مستأجر») + Outbox + ۱۸ سرویس هسته سند منبع (ADR-009).

## توسعه در سندباکس

```bash
bun run check      # دروازه ساختار/مستندات — باید «قبول» بدهد (ADR-007)
bun run lint        # بررسی کیفیت — باید همیشه پاک باشد
bun run db:push     # اعمال تغییرات schema.prisma
bunx tsx scripts/seed.ts   # داده اولیه (پاک‌سازی + seed کامل)
```

- dev سرور روی پورت ۳۰۰۰ خودکار اجراست — دست نزنید
- سرویس بلادرنگ: `mini-services/realtime/` — راه‌اندازی دستی در `docs/runbook/RB-01-services.md`
- تست مرورگر: از گیت‌وی پورت ۸۱ (نه ۳۰۰۰ مستقیم)
