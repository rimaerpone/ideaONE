# واژه‌نامه دامنه — کاشی/سرامیک و سازمان هلدینگ

وضعیت: **فعال** | مالک: محصول | بازنگری: ۱۴۰۵/۰۶/۰۵

> **قانون**: نام فیلدها در دیتابیس از ستون «انگلیسی» و لیبل UI از ستون «فارسی» این جدول انتخاب می‌شود. واژه جدید بدون ثبت در این جدول در کد استفاده نمی‌شود.

## دامنه تولید کاشی/سرامیک

| فارسی | انگلیسی (نام فیلد) | تعریف عملیاتی | نکته داده |
|---|---|---|---|
| خط محصول | `productLine` | خانواده محصول از نظر فرآیند/دکور (پرسلان پولیش، پرسلان مات، کاشی دیوار، روستیک، مارمریت) | متن آزاد v1 → واژه‌نامه کنترل‌شده در P4 |
| ابعاد | `size` | طول×عرض سانتی‌متری؛ نمایش فارسی مثل «۶۰×۶۰» | رشته؛ فرم استاندارد در P4 اعمال می‌شود |
| رنگ | `color` | رنگ غالب آیتم (سفید، خاکستری، بژ، کرم، کهربایی…) | متن آزاد v1 |
| سطح | `surface` | پرداخت سطح: پولیش / مات / براق / ساتن / روستیک / LT | اختیاری v1 |
| تون | `tone` | بچ رنگی کوره — محصول «همان کد» با تون متفاوت رنگ متفاوتی دارد | مقادیر v1: A/B/C یا خالی؛ کلید موجودی |
| کالیبر | `caliber` | بچ ابعادی کوره — تفاوت میلی‌متری ضخامت/اندازه بین دفعات پخت | مقادیر v1: ۱/۲/۳ یا خالی؛ کلید موجودی |
| درجه | `grade` | طبقه کیفیت: درجه ۱ (تولید اصلی) / درجه ۲ (مرکب/انتخاب دوم) / ضایعات | مقادیر v1: `1`/`2`/`w`؛ کلید موجودی |
| مترمربع | `m2` / `qtyM2` | واحد پایه اندازه‌گیری موجودی | `Float`؛ منفی فقط در سند حواله/شمارش |
| کارتن | `carton` | واحد شمارش لجستیکی؛ هر کارتن `cartonArea` مترمربع | تبدیل در سطح مدل محصول |
| پالت | `pallet` | واحد حمل/انبارش؛ هر پالت `cartonsPerPallet` کارتن | تبدیل نمایشی |
| انبار محصول | `FINISHED` | انبار کالای نهایی | `Warehouse.kind` |
| انبار مواد اولیه | `RAW` | خاک، لعاب، فریت، جعبه | `Warehouse.kind` |
| انبار ضایعات | `WASTE` | درجه ۲ و ضایعات | `Warehouse.kind` |
| رسید | `RECEIPT` | سند افزایش موجودی (از تولید/خرید/مرجوعی) | `WarehouseDoc.type` |
| حواله | `ISSUE` | سند کاهش موجودی (فروش/مصرف/هدررفت) — مقدار منفی | `WarehouseDoc.type` |
| انتقال بین‌انباری | `TRANSFER` | کسر از مبدأ + افزودن به مقصد در یک تراکنش | `WarehouseDoc.type` |
| شمارش | `COUNT` | اصلاح مغایرت فیزیکی — کسری منفی/افزایشی مثبت | `WarehouseDoc.type` |
| قطعی‌سازی | `post` | اعمال تراکنشی سند روی موجودی؛ برگشت‌ناپذیر در پایلوت | `WarehouseDoc.status: DRAFT→POSTED` |
| کوره رولری | — | کوره پخت پیوسته (اصطلاح تولید؛ فعلاً فقط در متن آزاد طرف حساب) | P7 |

## دامنه سازمانی و اتوماسیون

| فارسی | انگلیسی (نام فیلد) | تعریف |
|---|---|---|
| شرکت هلدینگ | `Company.type=GROUP` | شرکت چتر؛ نمی‌تواند رکورد عملیاتی (نامه/سند/درخواست) ثبت کند — فقط دید تجمعی |
| شرکت عملیاتی | `Company.type=COMPANY` | مستأجر (tenant) واقعی؛ مالک داده عملیاتی — ADR-002 |
| کارتابل | `cartable` | نامه‌هایی که `currentHolder` آن‌ها کاربر است و `IN_PROGRESS` هستند |
| نامه وارده | `INCOMING` | دریافتی از بیرون شرکت؛ `senderTitle` الزامی منطقی |
| نامه صادره | `OUTGOING` | ارسالی به بیرون؛ `receiverTitle` |
| نامه داخلی | `INTERNAL` | بین واحدهای همان شرکت |
| ارجاع | `REFER` | انتقال مسئولیت اقدام به کاربر دیگر + ثبت در زنجیره `LetterReferral` |
| عطف | — | ارجاع نامه به نامه دیگر (الزام SRS؛ در v1 نداریم → P2-T9) |
| محرمانگی | `confidentiality` | عادی / محرمانه / سری — «سری» برای AI مسدود است |
| فوریت | `urgency` | عادی / فوری |
| مهلت اقدام | `deadlineAt` | تاریخ موعد؛ < ۳ روز = نزدیک به مهلت، گذشته = قرمز |
| رکورد طلایی | `golden record` | رکورد مرجع گروهی شرکا (نام + شناسه ملی) — نسخه واحد برای کل هلدینگ |
| نمونه شرکتی | `PartnerInstance` | تنظیمات هر شرکت برای همان شریک: کد حساب، سقف اعتبار، شرایط |
| شماره سند سالانه | `DocCounter` | شمارنده ترتیبی per-company × scope × سال جلالی — مثال: نامه ۱۴۰۵/۴۲ |
| انسان در حلقه | `HITL` | هیچ خروجی AI بدون تأیید صریح ذخیره نمی‌شود |
| سجل حسابرسی | `AuditLog` | چه کسی، چه زمانی، چه عملی، روی چه رکوردی |
| رویداد خروجی | `OutboxEvent` | رویداد دامنه درون‌برنامه‌ای برای یکپارچگی آینده (بدون broker) |
| دامنه دید | `scopeCompanyIds` | آرایه شرکت‌های مجاز به دیدن: هلدینگ = همه عضوها، غیر آن = فقط شرکت فعال |

## کدها و شناسه‌های ایرانی

| فارسی | انگلیسی | قاعده اعتبارسنجی |
|---|---|---|
| کد ملی اشخاص حقیقی | `nationalId` (۱۰ رقم) | الگوریتم رقم کنترل — `verifyIranianNationalId` |
| شناسه ملی اشخاص حقوقی | `nationalId` (۱۱ رقم) | الگوریتم jurídico — `verifyIranianLegalId` |
| سال جلالی | `year` (DocCounter) | از `currentJalaliYear()` — تبدیل تست‌شده با ۵ تاریخ مرجع |
