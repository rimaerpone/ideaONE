- هر سند docs/ = وظیفه نگهداشت مستمر (بازنگری فصلی) — در چرخه sprint جداگانه.
- P0-T18 توسعه آینده: consumers per event-type (letter.*/doc.*/request.*) + idempotency key + dead-letter + dashboard پایش (P2).
- P0-T20 به: IP-block موقتی + افزایش نمایی + قفل حساب + اعلان ادمین.
- P0-T26 توسعه آینده: آپلود در فرم ثبت نامه (P1-T33)، پیش‌نمایش پیوست (P2-T2)، OCR پیوست (P5)، کانکتورهای زنده (P2+).
