## نکات گسترش (هر Epic چگونه صدها زیروظیفه می‌شود)

- **DataGrid**: هر نما = زیروظیفه «تعریف ستون‌ها» (ترتیب/عرض/قالب/خروجی) → ۱۰ نما × ~۸ ستون ≈ ۸۰ زیروظیفه.
- **CRUD کاربر**: هر فیلد = اعتبارسنجی + خطا فارسی + تست (≈۱۲ فیلد) + جریان دعوت با رمز اولیه/ایمیل فعال‌سازی.
- **پالت فرمان**: هر دامنه (نامه/محصول/شریک/سند/کاربر) = ایندکس + قالب نتیجه + تست فارسی.
- **RBAC**: هر خانه ماتریس (۴ نقش × ~۲۵ عملیات = ۱۰۰ خانه) = یک تست متقاطع مستند.
