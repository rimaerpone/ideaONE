# فاز P10 — یکپارچگی، انطباق و خروج از سندباکس (Integration & Compliance)

وضعیت: برنامه | گیت: **بهره‌برداری** | پیش‌نیاز: G3 (شروع تدریجی)؛ تکمیل با G5
هدف: پلتفرم آماده زندگی واقعی شود: API عمومی، ایمپورت/ایکسپورت سازمانی، پشتیبان‌گیری خودکار، سخت‌سازی امنیتی، مقدمات مودیان و مهاجرت از SQLite/سندباکس به زیرساخت اختصاصی.

> اصل: «چرخ را در سندباکس اختراع نکن» — هر چیزی که در زیرساخت نهایی باید بازنویسی/جایگزین شود، اینجا فقط «تصمیم و مستندسازی» می‌شود (ADR)، پیاده‌سازی در محیط مقصد.

## نکات گسترش

- API عمومی: هر منبع (letters/stock/products/…) = CRUD + قالب خطا + مثال (×۱۰ منبع).
- Webhooks: هر type رویداد = قرارداد payload + امضا + مستند مصرف (×۱۵ رویداد).
- مهاجرت: هر مدل = نگاشت نوع داده + تست شمار/جمع + مرز داده تاریخی (۲۱ مدل).
- ممیزی امنیتی: هر یافته = ریسک + اصلاح + آزمون مجدد.
