## ۲. نکات گسترش

- برندینگ تصویری (لوگو per-company در هدر/چاپ) → وظیفه P4 مستردیتا (#۳۶ پژوهش ۰۲).
- تم‌های فصلی/شخصی‌سازی رنگ آزاد (رنگ دلخواه خارج پالت) → پس از G3.
- صدا/زنگ اعلان قابل تنظیم → P5 گردشکار ( همراه نوتیفیکیشن‌های بیشتر).
- حالت «جلسه نمایشی» (تم دموی روشن با بنر) → در صورت نیاز بازاریابی.

## ۳. ریسک‌ها و تصمیم‌ها

- **بدون فلش تم**: هیدرات اولیه باید تم ذخیره‌شده را قبل از رندر بگذارد — اسکریپت کوچک sync در `<head>` (بدون FOUC تاریک).
- **recharts و توکن**: رنگ سری‌ها از CSS var خوانده شود نه literal — در بازنویسی نمودارهای داشبورد (D7) رعایت شود.
- **پرچم per-company vs per-user**: رنگ سازمان = شرکت (مدیر می‌گذارد)؛ تراکم/فونت/تم روشن-تاریک = سلیقه شخصی — تفکیک دو کلید در io.ui.v1 و context برند.
- **compact و هدف لمسی**: موبایل همیشه cozy می‌ماند (هدف لمسی ۴۴px) — compact فقط ≥lg.
