# فاز P3 — انبار نسل ۲ (Inventory v2)

وضعیت: برنامه | گیت: مشارکت در **G3** (با P4) | پیش‌نیاز: G2
هدف: انبار در سطح «دفاتر دارایی»: کارت حساب کالا، شمارش رسمی با مغایرت‌سنجی، ارزش‌گذاری، بارکد، چاپ بارگیری — بدون خطای موجودی.

## نکات گسترش

- کارت حساب: هر ستون گزارش (باقی‌مانده ریالی، تعداد تراکنش، میانگین روزانه) = زیروظیفه.
- شمارش: شمارش چرخه‌ای (cycle count per-انبار)، شمارش مقطعی، شمارش کندوکت — هرکدام گردشکار جدا.
- بارکد: QR دو-بعدی با payload کامل واریانت + چاپ روی سربرگ بارگیری.

## ریسک‌ها

| ریسک | پاسخ |
|---|---|
| مهاجرت partnerName → FK | اجرای دو-مرحله‌ای + نگه‌داشتن legacy + گزارش آشتی |
| سند معکوس سوءاستفاده | مجوز مدیر + دلیل الزامی + زنجیره ارجاع + audit |
| اسکن بارکد روی تبلت‌های قدیمی انبار | fallback تایپ دستی همیشه موجود |
