# فاز P4 — مستردیتا و شرکا نسل ۲ (Master Data & Partners v2)

وضعیت: آغاز زودهنگام | گیت: مشارکت در **G3** (با P3) | پیش‌نیاز: G2؛ هم‌زمان با P3
هدف: مستردیتای «اداره‌شده»: چرخه عمر محصول، واژه‌نامه‌های کنترل‌شده، لیست قیمت، CRUD و ادغام شرکا، ایمپورت انبوه.

> **P4-T0 اجرا شد (۱۴۰۵/۰۶/۰۹ — پس از قطع محیط، پیش از G2):** موتور کدگذاری ساختارمند «کد به‌عنوان جمله» بر مبنای سند واقعی شرکت («دستورالعمل کدگذاری محصولات» — upload/) — طرحواره‌ها داده‌محورند (CodeScheme/CodeSegment/CodeEnumValue)، کاشی = ترجمه کامل ۱۶ جزء سند + کد مادر (تبصره ۱-۲) + سه طرحواره عمومی (تجهیزات/قطعات یدکی/مواد اولیه) برای اثبات فراگیری. سرویس `core/coding` + APIهای schemes/compose/decode + کدساز زنده در فرم کالا (رنگ‌بندی اجزا + براکت مادر + رمزگشا + شمارنده طرح از DocCounter). تست: `scripts/test-coding.ts` (۴۳ سنجه) + `scripts/test-coding-ui.ts` (۱۹ سنجه مرورگر). **خاستگاه: خواسته مستقیم کارفرما** — «روشی که برای همه کالا و تجهیزات و… استفاده بشه».

## نکات گسترش

- واژه‌نامه‌ها: هر دسته (خط/رنگ/سطح/ابعاد/شهر) = CRUD + ترتیب + مترادف‌های جستجو.
- لیست قیمت: لیست فصلی/کمپینی + تأیید دومرحله‌ای قیمت جدید (مدیر مالی بعداً).
- اشخاص تماس: تقویم پیگیری تماس + یادآور (اتصال به P5).
- merge شرکا: گزارش تشخیص تکراری با امتیاز اطمینان + مرز انسانی.

## ریسک‌ها

| ریسک | پاسخ |
|---|---|
| واژه‌نامه سخت‌گیرانه مانع کار روزانه | افزودن سریع مقدار جدید با «+ افزودن…» (با مجوز) |
| merge شرکا اشتباه | پیش‌نمایش کامل + undo جلسه‌ای + audit مفصل |
| تاریخچه قیمت حجم بالا | ایندکس بازه‌ای + آرشیو سالانه |
