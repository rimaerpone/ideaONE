# فاز P5 — موتور گردشکار پیکربندی‌پذیر (Workflow Engine)

وضعیت: برنامه | گیت: مشارکت در **G4** | پیش‌نیاز: G3 (P1+P2+P3+P4)
هدف: تعریف گردشکار «داده» شود نه کد: مسیرهای تأیید چندسطحی، جانشینی، SLA و تشدید — چارچوب مشترک نامه/درخواست/مرخصی/چک.

## نکات گسترش

- هر الگوی گردشکار (مرخصی/خرید/چک/امضای قرارداد) = تعریف داده + فرم + قواعد + گزارش (۴×N زیروظیفه).
- طراح مسیر: هر نوع گام (تأیید ساده/شرطی/موازی/امضا/فرم) = کامپوننت + اعتبارسنجی جدا.
- گزارش SLA: هر بازه/گروه/نوع = یک گزارش ذخیره‌شده.
