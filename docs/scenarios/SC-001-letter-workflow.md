# SC-001 — چرخه کامل نامه اداری (ثبت تا بایگانی)

وضعیت: فعال | ماژول: letters/cartable | SPEC: `modules/letters/SPEC.md` | بازنگری: ۱۴۰۵/۰۶/۰۵

## بازیگران

- **دبیر اداری** (dabir.arad — OPERATOR آراد سرام): ثبت‌کننده نامه وارده
- **مدیر شرکت** (ceo.arad — MANAGER آراد سرام): گیرنده ارجاع و تأییدکننده
- **کارشناس بازرگانی** (فرضی با نقش OPERATOR): گیرنده دوم ارجاع

## پیش‌شرط‌ها

1. هر سه کاربر عضو شرکت «آراد سرام پیشرو» (ARAD) هستند.
2. dabir با شرکت فعال ARAD وارد شده (نه هلدینگ).
3. سرویس بلادرنگ برای هر دو مرورگر فعال است.

## حالت‌های مرزی

- **مهلت گذشته**: کارت کارتابل پس‌زمینه قرمز ملایم + «مهلت: … (گذشته)» — پیش از هر اقدام.
- **نامه بدون ارجاع اولیه**: status=DRAFT؛ فقط سازنده اقدام می‌کند؛ در تب «ثبت‌شده توسط من».
- **بازگشایی از آرشیو**: فقط REFER مجاز — زنجیره ادامه می‌یابد و آرشیو باطل.
- **کاربر غیرفعال**: در Select ارجاع نمی‌آید (isActive=false).
- **حلقه ارجاع به خود**: خودِ کاربر از لیست ارجاع فیلتر شده (UI) + ارجاع به خود معنای گردش ندارد.
- **متن خیلی بلند**: pre-wrap با اسکرول دیالوگ — بدون بریدن.
