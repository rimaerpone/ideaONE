# SC-008 — چرخه عمر ماژول: فعال/غیرفعال‌سازی سراسری و شرکتی

وضعیت: فعال | ماژول: platform (modules-view) | معماری: 06-module-registry.md | بازنگری: ۱۴۰۵/۰۶/۰۵

## بازیگران

- **مدیر پلتفرم** (admin — isAdmin): کلید سراسری
- **مدیر شرکت** (ceo.arad — ADMIN/MANAGER شرکت): در v1 toggle شرکتی فقط ADMIN

## منطق دوکلیدی

```
دید منو = PlatformModule.status==='ACTIVE'  (کلید سراسری)
          AND (activation ندارد OR enabled)  (کلید شرکتی)
```

## شاخه‌ها و مرزی

| حالت | رفتار |
|---|---|
| toggle شرکتی وقتی شرکت فعال GROUP است | غیرفعال با توضیح (فعال‌سازی به شرکت عملیاتی) |
| toggle سراسری توسط غیر-isAdmin | دکمه مخفی/غیرفعال؛ سرور هم رد |
| ماژول خاموش اما targetView اعلان قدیمی همان است | اعلان کلیک می‌شود → نما نیست → fallback داشبورد + toast راهنما «ماژول مقصد اعلان فعال نیست» (✅ P1-T17 انجام شد — تست E2E با خاموش/روشن سراسری warehouse) |
| ماژول جدید افزوده شود (چک‌لیست معماری 06 §4) | پیش‌فرض INACTIVE تا فعال‌سازی آگاهانه |
| فعال‌سازی شرکتی ماژولِ INACTIVE سراسری | بی‌اثر — کلید سراسری مسلط است |
